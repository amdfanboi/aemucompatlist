# AEmulator Compatibility List
List of firmwares compatible with :
- Original AEmulator by uxazu - https://github.com/uxazu/AEmulator
- AEmulator Plus by somerandomusernam2 - https://github.com/somerandomusernam2/AEmulator-Plus

All firmwares have been tested on Xiaomi Redmi 12 (MediaTek Helio G88, Mali-G52 MC2, Android 15).
